# Hey, I'm Ron 👋

### Systems engineering · Cloud infrastructure · AI automation

I build and run infrastructure, connect business systems, and automate the work between them. My background spans hardware repair, global production support, and hands-on engineering for small businesses.

Today, I work independently on self-hosted platforms, cloud deployments, and AI-powered workflows—from provisioning virtual machines to giving teams a natural-language interface for their everyday tools.

---

### What I build

🖥️ **Infrastructure teams can rely on**  
Virtualized environments on Proxmox and VMware, storage with TrueNAS, and cloud resources across AWS, Azure, and Google Cloud. I use Terraform and Ansible for repeatable provisioning and configuration.

⚙️ **Automation that connects the dots**  
Python scripts and workflows in n8n, Make, Zapier, and Power Automate that connect lead management, ticketing, scheduling, notifications, and business data.

🤖 **AI integrated into everyday tools**  
GPT-powered agents for managing project work through natural language, OCR and RAG document pipelines, and local LLM experiments on NVIDIA GPUs.

🚀 **Business applications and delivery pipelines**  
Client CRM systems, Python + n8n ETL pipelines into replicated PostgreSQL, and CI/CD with GitHub Actions and Forgejo/Woodpecker CI.
